Citadel UI

Living: the code wins 2026-11-02 Builds on the survey of the four apps (shared specs/ui-library/survey-2026-11.md) and theme.css (#269) Checked against Citadel 4d99ace + #283

The look and the parts Citadel serves at /apps/_citadel/ui/ for Mandate, Theory of Crafting and Peek Auras, and use itself, so the four stop drifting apart. Every token and part below is drawn live; flip the theme at the top to see both modes. This is the living home (#283): when it and the code disagree, the code wins, and a change to a token, part or rule updates this page in the same commit. The tokens live in public/style.css (served as theme.css by src/theme.ts), the parts in public/ui/, and test/ui-contract.test.ts holds what apps rely on. How apps use it: the citadel:contraption-ui kit skill.

Built so far (#283): the tokens, ui/base.css and ui/markdown.js. The composer (ui/composer.js, #285) and the chat kit (ui/chat.js, #284) are live; their specimens below copy the look, and the code is mountComposer and mountChat. ui/markdown.js ships Citadel's existing markdown look, moved from its style.css; the restyle in the Markdown specimen (tables in a box, 22/18/16 headings) isn't built yet.

        Rules

        What every screen of every app is held to. Each shows the right way (green) beside the wrong way (red).

        1. Equal, non-zero room above and below

        In every box, bar, button, row and chip (Cara's standing rule). Blue is padding, green is content.

        ✓ Even
        waiting
        Row with 8px above and below

        Fixed control height and centred content, or the same block padding top and bottom.

        ✕ Top-heavy text
        waiting
        Row with 2px above, 12px below

        The text rides high; a zero on either side looks cut off.

        2. Text on accent uses --citadel-on-accent

        ✓ var(--citadel-on-accent)
        Land it

        Readable in both modes.

        ✕ #fff (or var(--citadel-surface))
        Land it

        Flip to dark: white on orange drops to about 2.3:1.

        3. Inputs are 16px on phones

        ✓ .cui-input

        Now …. iOS Safari leaves the page alone on focus.

        ✕ 13.5px (ToC) or 15px (Citadel, Mandate)

        Now …. On an iPhone, tapping it zooms the whole page in.

        4. Focus is visible on keyboard focus only

        ✓ :focus-visible

        No ring after a click; a clear ring when you Tab in.

        ✕ :focus

        A ring stays on every clicked button. (The other wrong, outline: none, loses keyboard users.)

        5. Motion respects reduced motion

        ✓ var(--citadel-motion-slow)
        Sheet

        With reduced motion: the sheet just appears; the spinner holds still.

        ✕ A fixed 600ms, no media query
        Sheet

        Slides and spins whatever the person asked for (Mandate and Peek today).

        6. External links open a new tab

        ✓ target="_blank" rel="noopener"
        MDN on link targets
        <a href="…" target="_blank" rel="noopener">
        ✕ target="_top" (ToC today)
        MDN on link targets

        When the app is framed in Citadel, this replaces Citadel's whole window. (Click it: this page stops it.)

        7. No inline styles in what a component writes

        Citadel's CSP is default-src 'self', so style="" and <style> in markup are blocked there. Components bring a constructed stylesheet (as drawers.js does) or use ui/base.css classes.

        ✓ Classes + a constructed sheet 
        const sheet = new CSSStyleSheet();
sheet.replaceSync(CSS);
document.adoptedStyleSheets =
  [...document.adoptedStyleSheets, sheet];
row.innerHTML =
  '<span class="cui-chip" data-tone="warn">waiting</span>';
        ✕ style="" in an HTML string 
        row.innerHTML =
  '<span style="color:#b45309">waiting</span>';
// Citadel: "Refused to apply inline style
// because it violates … default-src 'self'"

        ✕ #c2410c

        Stays light mode's orange in dark, and misses Citadel's next colour change.

        11. A chat's box has the caret on desktop

        Cara, 2026-11-04: If I have a screen with a chat open in citadel, it should default focus so I dont have to click on the chat box to type into it. The composer does it: mountComposer(el, { autofocus }), on by default.

        ✓ When the chat comes up, the window comes back, or a dialog over it closes

        On desktop, and only when nothing else has the caret (or, as the chat opens, the link or button that opened it). Open a chat and type: the words land in the box.

        ✕ On a redraw, a new message, or out of another field

        Detail calls made

        The minion's picks on details (#282, 2026-11-02); say if any should go the other way.

        • Type sizes get names too (--citadel-size-body 15, -small 13, -meta 12, -h1…-h3), so apps stop picking their own.
        • The class-only parts ship as one linked ui/base.css (buttons, inputs, chips, notices, spinner, focus ring); the script components keep constructed sheets. A linked file is CSP-clean and needs no import.
        • Small buttons are 40px on phones like the rest; "small" only shrinks them on desktop.
